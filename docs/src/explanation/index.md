# Concepts

Use this route when you want context for the choices you make in a Makie
figure. The current [examples](../examples.md) show runnable results, and the
[rendering API](../api/rendering.md) provides exact API facts.

This route will gather bounded explanations of reader-visible topics such as
coordinates, ranges, galleries, image matrices, and saved figures. Use the
[documentation map](../index.md) to choose a tutorial, a how-to guide, or
reference material. Use [choose PhyloPic images](../how-to/choose-phylopic-images.md)
for image-record selection and [cache repeated PhyloPic queries](../how-to/repeated-queries.md)
for the repeated-query workflow.
