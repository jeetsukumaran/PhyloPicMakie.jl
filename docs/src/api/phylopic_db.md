# PhyloPicDB

HTTP client for the [PhyloPic](https://www.phylopic.org/) API.
Provides node resolution, image fetching, and metadata extraction.

For task-oriented selection guidance, see
[choose PhyloPic images](../how-to/choose-phylopic-images.md) and
[cache repeated PhyloPic queries](../how-to/repeated-queries.md).
